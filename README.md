# 우리 결혼 준비 대시보드 💍

2027년 10~11월 결혼을 목표로 두 사람이 함께 준비할 내용을 관리하기 위한 웹 대시보드입니다.

## 관리 항목
- 지금 해야 할 일과 진행률
- 월별 결혼 준비 일정
- 웨딩홀 후보 비교
- 스드메·본식사진·영상·예복·한복·예물 등 업체 비교
- 총예산·실제 계약금액·계약금·잔금 관리
- 하객 관리
- 계약 전 필수 확인사항
- 신혼여행 후보 비교

웨딩홀 후보와 예상가격은 미리 넣지 않았습니다. 실제 상담한 후보와 견적을 직접 입력해 비교할 수 있습니다.

## 데이터 저장
입력값은 브라우저 localStorage에 저장됩니다. 같은 브라우저에서는 새로고침해도 유지되지만 다른 기기와 자동 동기화되지는 않습니다.

## 다음 확장
두 사람이 휴대폰과 PC에서 동시에 사용하려면 Google Sheets, Firebase 또는 Supabase 등 공동 데이터 저장 기능을 연결할 수 있습니다.
